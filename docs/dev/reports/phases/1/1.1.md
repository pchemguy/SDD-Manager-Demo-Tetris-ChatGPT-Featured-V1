## Finding and correction

R1, tools/check.py run, medium: the original group-only timeout handler could leave a detached child alive. A controlled reproduction failed the expected no-live-child assertion. The review repair establishes Linux child-subreaper ownership, verifies parent relationships through procfs, translates namespace IDs and kills/reaps only adopted owned descendants under a finite cleanup deadline. This host omits the task/children interface, so the verified PPid scan is used. A second regression showed that normally exited descendants must be reaped as ordinary cleanup rather than falsely reporting a failed check. Both regressions pass with the corrected lifecycle. No unrelated process or host policy is changed.
